# 💬 AI Chatbot with Memory

A conversational AI chatbot with full memory that remembers your entire conversation, powered by Groq + LLaMA 3.

## 🚀 Features
- 🧠 Full conversation memory across the session
- 🎭 Multiple personality modes (tutor, coach, programmer, advisor)
- 🌡️ Adjustable creativity/temperature
- 🗑️ Clear chat option
- ⚡ Ultra-fast responses via Groq

## 🛠️ Tech Stack
- Python, Streamlit
- Groq API + LLaMA 3.3 70B
- LangChain

## ▶️ How to Run
```bash
git clone https://github.com/rohithvandadi07-ux/ai-chatbot.git
cd ai-chatbot
pip install -r requirements.txt
streamlit run app.py
```
